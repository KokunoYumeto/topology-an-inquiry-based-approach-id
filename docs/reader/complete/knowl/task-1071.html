Butir 19.5.c.

Kita akan melihat bahwa lingkungan-lingkungan minimal dari \(X\) terhubung lintasan. Di sini kita akan mengilustrasikannya dengan \(U_d\text{.}\)
(i)
Misalkan \(p : [0,1] \to X\) didefinisikan oleh
\begin{equation*} p(t) = \begin{cases}b \amp \text{ jika } 0 \leq t \lt \frac{1}{2} \\ d \amp \text{ jika } \frac{1}{2} \leq t \leq 1. \end{cases} \end{equation*}
Tunjukkan bahwa \(p\) merupakan lintasan dalam \(U_d\) dari \(b\) ke \(d\text{.}\)
(ii)
Misalkan \(p : [0,1] \to X\) didefinisikan oleh
\begin{equation*} p(t) = \begin{cases}c \amp \text{ jika } 0 \leq t \lt \frac{1}{2} \\ d \amp \text{ jika } \frac{1}{2} \leq t \leq 1. \end{cases} \end{equation*}
Tunjukkan bahwa \(p\) merupakan lintasan dalam \(U_d\) dari \(c\) ke \(d\text{.}\)
(iii)
Jelaskan mengapa \(U_d\) terhubung lintasan.
