Latihan 2.

Misalkan \(X\) merupakan himpunan bilangan real dengan topologi metrik Euklides standar dan misalkan \(Y\) merupakan bilangan real dengan topologi diskret.

(a)

Jelaskan mengapa himpunan semua “interval horizontal” berbentuk
\begin{equation*} I= (a,b) \times \{c\} = \{(x,c) \mid a \lt x \lt b\} \end{equation*}
merupakan basis bagi topologi hasil kali pada \(X \times Y\text{.}\)

(b)

Carilah interior dan penutup setiap subhimpunan \(X \times Y\) berikut.
(i)
\(A = \{(x,0) \mid 0 \leq x \lt 1\}\)
(ii)
\(B = \{(0,y) \mid 0 \leq y \lt 1\}\)
(iii)
\(C = \{(x,y) \mid 0 \leq x \lt 1, 0 \leq y \lt 1\}\)
