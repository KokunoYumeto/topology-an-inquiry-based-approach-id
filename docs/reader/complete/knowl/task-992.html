Butir 9.b.

Wajar jika kita menduga bahwa ruang terhubung bersifat terhubung secara lokal. Namun, hal itu tidak selalu benar. Tinjau ruang \(X = A \cup B\) sebagai subruang dari \(\R^2\) dengan topologi metrik Euklides standar, dengan \(A = \{(x,y) \mid x \text{ irasional dan } 0 \leq y \leq 1\}\) dan \(B = \{(x,y) \mid x \text{ rasional dan } -1 \leq y \leq 0\}\text{.}\)
(i)
Jelaskan mengapa \(X\) terhubung.
(ii)
Tunjukkan bahwa \(X\) tidak terhubung secara lokal.
Petunjuk.
