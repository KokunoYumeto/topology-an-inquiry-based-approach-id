Kegiatan 12.6.

Misalkan \(X = \{a,b,c,e\}\) dan \(\tau = \{\emptyset, \{a\}, \{b\}, \{a,b\}, X \}\text{.}\) Jelaskan mengapa tidak mungkin ada metrik \(d : X \times X \to \R\) sedemikian sehingga himpunan terbuka dalam topologi metrik adalah himpunan-himpunan dalam \(\tau\text{.}\)
