Misalkan \(A = \{1, 2, 3\}\text{,}\) \(B = \{a, b, c, d\}\text{,}\) dan \(C = \{\alpha, \beta, \gamma\}\text{.}\) Definisikan \(f : A \to B\text{,}\) \(g : A \to B\text{,}\) dan \(h : B \to C\) dengan
\begin{equation*} f(1) = b, \ f(2) = c, \ f(3) = a\text{,} \end{equation*}
\begin{equation*} g(1) = d, \ g(2) = c, \ g(3) = d, \text{ dan } \end{equation*}
\begin{equation*} h(a) = \gamma, \ h(b) = \alpha, \ h(c) = \beta, \ h(d) = \alpha\text{.} \end{equation*}
