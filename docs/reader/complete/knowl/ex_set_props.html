Latihan 3.

Misalkan \(A\) dan \(B\) merupakan himpunan bagian dari suatu himpunan semesta \(U\text{,}\) dan anggap pula setiap himpunan lain yang muncul di bawah merupakan himpunan bagian dari himpunan semesta yang sama. Buktikan hukum asosiatif dan distributif. Dengan kata lain, buktikan setiap pernyataan berikut.

(a)

\((A \cap B) \cap C = A \cap (B \cap C)\)

(b)

\((A \cup B) \cup C = A \cup (B \cup C)\)

(c)

\(A \cap (B \cup C) = (A \cap B) \cup (A \cap C)\)

(d)

\(A \cup (B \cap C) = (A \cup B) \cap (A \cup C)\)
