Misalkan \(p\) lintasan dari \(a\) ke \(b\) dan \(q\) lintasan dari \(b\) ke \(c\) dalam ruang \(X\text{.}\) Hasil kali lintasan \(q*p\) adalah lintasan dalam \(X\) yang didefinisikan oleh
\begin{equation*} (q*p)(x) = \begin{cases}p(2x) \amp \text{ untuk } 0 \leq x \leq \frac{1}{2} \\ q(2x-1) \amp \text{ untuk } \frac{1}{2} \leq x \leq 1. \end{cases} \end{equation*}
