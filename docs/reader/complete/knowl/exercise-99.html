\begin{equation*} f(x) = \begin{cases}0 \amp \text{ jika } x \text{ irasional } \\ x \amp \text{ jika } x \text{ rasional. } \end{cases} \end{equation*}

(a)

Untuk fungsi \(f\) di atas, andaikan kedua salinan \(\R\) dilengkapi dengan topologi Euklides. Tunjukkan bahwa fungsi tersebut kontinu tepat di satu titik.

(b)

Dapatkah Anda melihat cara memperluas konstruksi ini untuk membentuk fungsi \(h: \R \to \R\) yang kontinu tepat pada sebarang himpunan berhingga dari titik-titik yang telah ditentukan?
