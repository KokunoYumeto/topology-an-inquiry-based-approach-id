Misalkan \(p : [0,1] \to X\) didefinisikan oleh
\begin{equation*} p(t) = \begin{cases}c \amp \text{ jika } 0 \leq t \lt \frac{1}{2} \\ d \amp \text{ jika } \frac{1}{2} \leq t \leq 1. \end{cases} \end{equation*}
Tunjukkan bahwa \(p\) merupakan lintasan dalam \(U_d\) dari \(c\) ke \(d\text{.}\)
