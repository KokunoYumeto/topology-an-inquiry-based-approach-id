Butir 18.11.b.

Misalkan \(D = \{(x,y) \mid x^2+y^2 \leq 4\}\) dalam \((\R^2, d_E)\text{.}\) Artinya, \(D\) merupakan cakram tertutup berjari-jari \(2\) pada bidang. Himpunan \(D\) tidak mempunyai titik pemutus. Akan tetapi, jika \(S = \{(x,y) \mid x^2+y^2 = 1\}\text{,}\) maka \(D \setminus S\) terdiri atas dua komponen terhubung: bola buka \(B((0,0),1)\) dan anulus \(\{(x,y) \mid 1 \lt x^2+y^2 \leq 4\}\text{,}\) sebagaimana diilustrasikan dalam Gambar 18.12. Jadi, \(S\) merupakan himpunan pemutus dari \(D\text{.}\)
