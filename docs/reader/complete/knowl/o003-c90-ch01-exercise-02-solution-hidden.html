Jika \(u\in Y\setminus X\text{,}\) maka \(u\in Z\) dan \(u\notin X\text{,}\) jadi \(u\in Z\setminus X\text{.}\) Untuk identitas kedua, anggota ruas kiri berada di \(Z\) tetapi tidak di \(Y\setminus X\text{.}\) Jika ia tidak di \(Y\text{,}\) ia berada di \(Z\setminus Y\text{;}\) jika ia di \(Y\text{,}\) kegagalan berada di \(Y\setminus X\) memaksanya berada di \(X\text{.}\) Arah sebaliknya diperiksa langsung dari dua kasus itu.
