Latihan 6.

Misalkan \((X_i, d_i)\) merupakan ruang metrik untuk \(i\) dari \(1\) sampai suatu bilangan bulat positif \(n\text{.}\) Misalkan \(X = \prod_{i=1}^n X_i,\ d: X \times X \to \R\) didefinisikan oleh
\begin{equation*} d(x,y) = \sqrt{\sum_{i=1}^n d_i(x_i,y_i)^2} \end{equation*}
apabila \(x = (x_1, x_2, \ldots, x_n)\) dan \(y = (y_1, y_2, \ldots, y_n)\) berada dalam \(X\text{.}\) Tunjukkan bahwa \(d\) merupakan suatu metrik pada \(\prod_{i=1}^n X_i\text{.}\)
