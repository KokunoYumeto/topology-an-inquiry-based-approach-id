Butir 18.1.h.

Himpunan \(A = X\) dalam \(X = \left\{(x, y) \in \R^2 \ \mid \ y = \frac{1}{x} \text{ atau } y = 0\right\}\) dengan himpunan-himpunan buka
\begin{equation*} \tau = \{U \cap X \ \mid \ U \text{ buka dalam topologi Euklides pada } \R^2\}\text{.} \end{equation*}
