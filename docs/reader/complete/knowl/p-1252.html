Misalkan \((X,d) = (\R^2,d_E)\text{,}\) misalkan \(A = \{(x,0) \mid x \in \R\}\) (sumbu \(x\) di \(\R^2\)), dan misalkan \(Z = \{(x,0) \mid 0 \lt x \lt 1\}\text{.}\) Perhatikan bahwa \(Z \subset A \subset X\text{;}\) kita dapat memandang \(Z\) sebagai subruang dari \(A\) maupun \(X\text{,}\) serta \(A\) sebagai subruang dari \(X\text{.}\)
