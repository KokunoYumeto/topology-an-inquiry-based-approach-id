Kegiatan 19.4.

Misalkan \((X,\tau)\) ruang topologi. Definisikan relasi pada \(X\) sebagai berikut:
\begin{equation} a \sim b \text{ jika terdapat lintasan dalam } X \text{ dari } a \text{ ke } b\text{.}\tag{19.1} \end{equation}

(a)

Jelaskan mengapa \(\sim\) merupakan relasi refleksif.

(b)

Jelaskan mengapa \(\sim\) merupakan relasi simetris.

(c)

Jelaskan mengapa \(\sim\) merupakan relasi transitif.
