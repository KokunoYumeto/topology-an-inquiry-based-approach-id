Program matematika / Mathematics program:
  • Program (Bahasa Indonesia)
  • Program (English)
  • Sumber asli / Authoritative original
Himpunan \(A\) terbuka dan tidak tertutup, sedangkan \(B\) tertutup dan tidak terbuka. Selain itu, \(A\) tidak memuat titik batas sekaligus titik limit \(0\) dan \(1\text{,}\) sedangkan \(B\) memuat keduanya.
