Maka \(B = C\text{.}\) Kita dapat menunjukkan bahwa pernyataan ini salah dengan memberikan contoh tandingan. Sebagai contoh, misalkan \(A = \{0,1\}\text{,}\) \(B=\{1\}\text{,}\) dan \(C = \{1,2\}\text{.}\) Maka \(A \cap B = \{1\} = A \cap C\text{,}\) tetapi \(B \neq C\text{.}\)
