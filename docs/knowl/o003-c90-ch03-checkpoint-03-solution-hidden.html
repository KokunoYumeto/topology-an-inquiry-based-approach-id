Setiap \((x_i-y_i)^2\) tak negatif, sehingga jumlahnya dan akar kuadratnya tak negatif. Karena \((x_i-y_i)^2=(y_i-x_i)^2\) untuk setiap \(i\text{,}\) menukar \(x\) dan \(y\) tidak mengubah jarak. Jika \(x=y\text{,}\) semua selisih nol dan jaraknya nol. Sebaliknya, jika jaraknya nol, maka \(\sum_i(x_i-y_i)^2=0\text{.}\) Semua suku tak negatif, jadi setiap suku nol; maka \(x_i=y_i\) untuk seluruh \(i\text{,}\) yakni \(x=y\text{.}\)
