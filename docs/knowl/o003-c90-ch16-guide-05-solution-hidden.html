Tidak ada titik yang dipetakan ke anggota himpunan kosong, sehingga \(p^{-1}(\emptyset)=\emptyset\text{.}\) Setiap topologi pada \(X\) memuat \(\emptyset\text{;}\) maka definisi \(\tau_Y\) memberi \(\emptyset\in\tau_Y\text{.}\)
Karena kodomain \(p\) adalah \(Y\text{,}\) sebenarnya \(p^{-1}(Y)=X\) untuk setiap fungsi \(p:X\to Y\text{;}\) asumsi surjektif diperlukan untuk konstruksi kuosien, tetapi tidak untuk identitas ini. Aksioma topologi memberi \(X\in\tau_X\text{,}\) sehingga \(Y\in\tau_Y\text{.}\)
