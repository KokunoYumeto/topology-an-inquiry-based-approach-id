Ambil fungsi sebarang \(f:X\to Y\text{,}\) titik sebarang \(a\in X\text{,}\) dan \(\epsilon>0\text{.}\) Pilih \(\delta=1\text{.}\) Jika \(d_X(x,a)<1\text{,}\) definisi metrik diskret memaksa \(x=a\text{.}\) Karena itu
\begin{equation*} d_Y(f(x),f(a))=d_Y(f(a),f(a))=0<\epsilon. \end{equation*}
Jadi setiap fungsi kontinu di setiap titik domain. Tidak ada syarat tambahan pada \(f\) atau pada metrik \(d_Y\text{.}\)
