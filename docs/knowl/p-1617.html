Nilai mutlak tak negatif, jadi \(d_T(x,y)\geq0\text{.}\) Jumlah dua nilai mutlak bernilai nol tepat ketika kedua selisih koordinat nol, yaitu tepat ketika \(x=y\text{.}\) Karena \(|x_i-y_i|=|y_i-x_i|\text{,}\) fungsi ini simetris. Untuk titik ketiga \(z\text{,}\) tulis \(x_i-y_i=(x_i-z_i)+(z_i-y_i)\text{.}\) Ketaksamaan nilai mutlak memberi \(|x_i-y_i|\leq|x_i-z_i|+|z_i-y_i|\) untuk \(i=1,2\text{.}\) Menjumlahkan kedua pertidaksamaan menghasilkan \(d_T(x,y)\leq d_T(x,z)+d_T(z,y)\text{.}\)
