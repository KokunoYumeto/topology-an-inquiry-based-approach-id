Solusi C.21.1.

Tak-negatif, identitas, dan simetri langsung dari definisi kasus. Untuk pertidaksamaan segitiga, jika \(x=y\) ruas kiri nol. Jika \(x\ne y\) dan \(z=x\) atau \(z=y\text{,}\) diperoleh kesamaan. Jika \(z\) berbeda dari keduanya, ruas kiri \(|x|+|y|\text{,}\) sedangkan ruas kanan \((|x|+|z|)+(|z|+|y|)=|x|+|y|+2|z|\text{,}\) yang tidak lebih kecil.
Pusat \(a\) selalu masuk karena jaraknya nol. Untuk \(x\ne a\text{,}\) \(d_H(x,a)=|x|+|a|<r\) tepat ketika \(|x|<r-|a|\text{.}\) Jika \(r\leq|a|\text{,}\) tidak ada titik tambahan. Jika \(r>|a|\text{,}\) titik tambahannya membentuk bola Euklides berpusat di asal dengan jari-jari \(r-|a|\text{.}\) Substitusi \(|(1/2,0)|=1/2\) dan \(|(3,4)|=5\) memberi dua kasus khusus.
