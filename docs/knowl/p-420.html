Suatu metrik pada ruang \(X\) adalah fungsi \(d : X \times X \to \R^+ \cup \{0\}\) yang memenuhi sifat-sifat berikut:
  1. \(d(x,y) \geq 0\) untuk setiap \(x,y \in X\text{,}\)
  2. \(d(x,y) = 0\) jika dan hanya jika \(x = y\) di dalam \(X\text{,}\)
  3. \(d(x,y) = d(y,x)\) untuk setiap \(x, y \in X\text{,}\) dan
  4. \(d(x,y) \leq d(x,z) + d(z,y)\) untuk setiap \(x,y,z \in X\text{.}\)
