Jelas \(d(f,g)\geq0\text{.}\) Jika \(f=g\text{,}\) maka seluruh selisih bernilai nol, sehingga \(d(f,g)=0\text{.}\) Sebaliknya, jika \(d(f,g)=0\text{,}\) maka untuk setiap \(t\in[a,b]\text{,}\) \(0\leq|f(t)-g(t)|\leq d(f,g)=0\text{.}\) Jadi \(f(t)=g(t)\) untuk setiap \(t\text{,}\) yakni \(f=g\text{.}\) Selanjutnya, \(|f(t)-g(t)|=|g(t)-f(t)|\) pada setiap \(t\text{,}\) maka \(d(f,g)=d(g,f)\text{.}\)
