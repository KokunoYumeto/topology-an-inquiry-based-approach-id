Latihan 3.

Jika \(x = (x_1, x_2, \ldots, x_n)\text{,}\) tetapkan \(|x| = \sqrt{x_1^2+x_2^2+ \cdots + x_n^2}\text{.}\) Untuk \(x = (x_1, x_2, \ldots, x_n)\) dan \(y = (y_1, y_2, \ldots y_n)\text{,}\) definisikan \(d_H: \R^n \times \R^n \to \R\) dengan
\begin{equation*} d_H(x,y) = \begin{cases}0 \amp \text{ jika } x=y \\ |x|+|y| \amp \text{ selain itu } . \end{cases} \end{equation*}
Fakta bahwa \(d_H\) merupakan metrik dikaji dalam Latihan 7. Misalkan \((X,d_X) = (\R^2, d_H)\) dan \((Y,d_Y) = (\R, d_E)\text{.}\) Definisikan \(f: X \to Y\) dan \(g: X \to Y\) dengan
\begin{equation*} f(x) = \begin{cases}0 \amp \text{ jika } x = (0,0) \\ 1 \amp \text{ selain itu } \end{cases} \ \text{ dan } \ g(x) = \begin{cases}0 \amp \text{ jika } |x|\lt 1 \\ 1 \amp \text{ selain itu } \end{cases}\text{.} \end{equation*}
Salah satu dari \(f\) dan \(g\) kontinu, sedangkan yang lain tidak. Tentukan yang mana, disertai bukti untuk masing-masing fungsi.
