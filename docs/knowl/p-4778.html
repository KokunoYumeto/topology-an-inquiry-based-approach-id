Petunjuk 2. Setiap interval terbuka di sekitar \(2\) memuat bilangan lebih besar dari \(2\text{.}\) Jika interval di sekitar \(3\) berjari-jari \(r\gt0\text{,}\) titik \(3+r/2\) berada di interval itu tetapi tidak berada dalam \(A\text{.}\) Gunakan ini untuk menyingkirkan kedua titik tersebut dari interior.
