Nilai fungsi di titik pangkal adalah \(f(1)=1\text{.}\) Tetapkan \(\epsilon_0=1\) dan ambil sebarang \(\delta>0\text{.}\) Untuk \(x=1-\delta/2\text{,}\) berlaku \(x<1\text{,}\) sehingga \(f(x)=-1\text{,}\) serta \(|x-1|=\delta/2<\delta\text{.}\) Akan tetapi,
\begin{equation*} |f(x)-f(1)|=|-1-1|=2\geq1=\epsilon_0. \end{equation*}
Jadi toleransi keluaran \(\epsilon_0\) gagal untuk setiap pilihan \(\delta\text{.}\) Ini tepat negasi kekontinuan di \(1\text{.}\)
