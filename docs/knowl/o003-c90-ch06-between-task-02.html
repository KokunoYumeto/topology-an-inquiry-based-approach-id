Pemeriksaan F.6. Kekontinuan fungsi identitas.

Untuk ruang metrik \((X,d)\text{,}\) buktikan bahwa fungsi identitas \(i_X:(X,d)\to(X,d)\text{,}\) dengan \(i_X(x)=x\text{,}\) kontinu. Rubrik: nyatakan pilihan \(\delta\) sebagai fungsi dari \(\epsilon\) dan hitung jarak keluaran.
