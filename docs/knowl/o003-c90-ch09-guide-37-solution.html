Solusi I.37.1.

Jika \(a=0\text{,}\) semua suku bernilai nol. Jika \(0\lt a\lt1\text{,}\) tulis \(1/a=1+h\) dengan \(h\gt0\text{.}\) Untuk \(\epsilon\gt0\text{,}\) pilih \(N\) sehingga \(1/(1+Nh)\lt\epsilon\text{.}\) Bagi \(n\geq N\text{,}\) pertidaksamaan Bernoulli memberi
\begin{equation*} 0\leq a^n=\frac{1}{(1+h)^n} \leq\frac{1}{1+nh}\leq\frac{1}{1+Nh}\lt\epsilon. \end{equation*}
Ini tepat definisi \(a^n\to0\text{.}\)
