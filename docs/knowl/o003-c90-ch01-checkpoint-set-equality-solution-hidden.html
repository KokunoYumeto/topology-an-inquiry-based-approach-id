Bukti yang dapat diperiksa selalu dimulai dengan anggota sembarang. Untuk contoh terakhir, jika \(n\) ganjil maka algoritma pembagian memberi \(n=4q+1\) atau \(n=4q+3\text{;}\) arah sebaliknya segera memberi \(n=2(2q)+1\) atau \(n=2(2q+1)+1\text{.}\) Jadi kedua inklusi terbukti. Satu contoh \(0\) cukup menggugurkan arah \(A\subseteq B\) pada contoh genap.
