Latihan 8.

Misalkan \(f(x) = 2x^2+1\) memetakan \(\R\) ke \(\R\text{,}\) dengan metrik Euklides pada domain maupun kodomain.

(a)

Misalkan \(\epsilon = \frac{1}{4}\text{.}\) Carilah nilai \(\delta\) sedemikian sehingga \(|x-1| \lt \delta\) mengakibatkan \(|f(x)-f(1)| \lt \epsilon\text{.}\) Anda dapat menggunakan Laboratorium epsilon-delta O003 2  untuk memeriksa nilai \(\delta\) Anda secara numerik.

(b)

Buktikan bahwa \(f\) kontinu di \(x=1\text{.}\)
