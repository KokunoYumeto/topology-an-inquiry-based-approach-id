Untuk sembarang untai \(x,y\text{,}\) ada urutan edit berhingga: hapus seluruh \(|x|\) huruf \(x\text{,}\) lalu sisipkan seluruh \(|y|\) huruf \(y\text{.}\) Jadi himpunan panjang urutan edit dari \(x\) ke \(y\) adalah subhimpunan tak kosong dari bilangan bulat tak negatif; menurut prinsip pengurutan baik, himpunan itu mempunyai minimum. Karena panjang urutan edit tak negatif, \(d_L(x,y)\geq0\text{.}\)
