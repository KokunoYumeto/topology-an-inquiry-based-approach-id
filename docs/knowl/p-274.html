Misalkan \(A\) dan \(B\) himpunan tak kosong, serta misalkan \(f: A \to B\) suatu bijeksi. Maka \(f^{ - 1} : B \to A\) merupakan fungsi, dan untuk setiap \(a \in A\) dan \(b \in B\text{,}\)
\begin{equation*} f( a ) = b \text{ jika dan hanya jika } f^{ - 1} ( b ) = a\text{.} \end{equation*}
