Contoh 3.6.

Misalkan \(X = \{a,b,c\}\) dan definisikan \(d: X \times X \to \R^+ \cup \{0\}\) dengan nilai-nilai pada Tabel 3.7.
Menurut definisi, kita mempunyai \(d(x,y) \geq 0\) untuk setiap \(x, y \in X\text{,}\) dengan \(d(x,y) = 0\) jika dan hanya jika \(x=y\text{.}\) Karena tabel tersebut simetris terhadap diagonalnya, kita dapat melihat bahwa \(d(x,y) = d(y,x)\) untuk setiap \(x,y \in X\text{.}\) Satu-satunya sifat yang masih perlu diverifikasi adalah pertidaksamaan segitiga. Jika \(d(x,y) = 0\text{,}\) maka
\begin{equation*} d(x,y) = 0 \leq d(x,z) + d(z,y) \end{equation*}
untuk setiap \(x,y,z \in X\text{.}\) Jika \(d(x,z) = 0\text{,}\) maka \(x=z\) dan
\begin{equation*} d(x,y) = d(z,y) \leq d(z,z) + d(z,y)\text{.} \end{equation*}
Jika \(d(z,y)=0\text{,}\) maka \(z=y\) dan
\begin{equation*} d(x,y)=d(x,z) \leq d(x,z)+d(z,y)\text{.} \end{equation*}
Dengan demikian, tersisa tiga kasus yang perlu dipertimbangkan, yaitu ketika \(x\text{,}\) \(y\text{,}\) dan \(z\) berbeda satu sama lain. Sekarang,
\begin{align*} d(a,b) \amp = 3 \leq 5+4 = d(a,c) + d(c,b),\\ d(a,c) \amp = 5 \leq 3+4 = d(a,b) + d(b,c),\\ d(b,c) \amp = 4 \leq 3+5 = d(b,a) + d(a,c)\text{.} \end{align*}
Jadi, \(d\) merupakan metrik pada \(X\text{.}\)
