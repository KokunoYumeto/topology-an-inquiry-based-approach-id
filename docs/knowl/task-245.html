Butir 3.a.

Ikuti langkah-langkah berikut untuk menunjukkan bahwa \(\sup(A+B) = \sup(A) + \sup(B)\text{.}\)
(i)
Misalkan \(x = \sup(A)\) dan \(y = \sup(B)\text{.}\) Tunjukkan bahwa \(x+y\) merupakan batas atas bagi \(A+B\text{.}\)
(ii)
Bagian sebelumnya menunjukkan bahwa \(A+B\) terbatas di atas sehingga memiliki supremum. Misalkan \(z = \sup(A+B)\text{.}\) Jelaskan mengapa \(z \leq x+y\text{.}\)
(iii)
Untuk menunjukkan bahwa \(z = x+y\text{,}\) kita harus membuktikan bahwa \(z\) tidak mungkin lebih kecil daripada \(x+y\text{.}\) Andaikan, demi memperoleh kontradiksi, bahwa \(z \lt x+y\text{.}\) Misalkan \(\epsilon = x+y-z\text{.}\) Gunakan hasil Latihan 2 untuk memperoleh kontradiksi.
