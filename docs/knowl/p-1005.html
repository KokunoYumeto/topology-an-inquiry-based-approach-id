Misalkan \(f\) fungsi dari \(\R\) ke \(\R\text{,}\) dengan domain dan kodomain dilengkapi metrik Euklides, yang didefinisikan oleh
\begin{equation*} f(x) = \begin{cases}\sin\left(\frac{1}{x}\right) \amp \text{ jika } x \neq 0 \\ 0 \amp \text{ jika } x = 0. \end{cases} \end{equation*}
