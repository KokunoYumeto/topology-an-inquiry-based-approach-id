Untuk \(n=4\text{,}\) fungsi bukan metrik karena \(d(1,5)=0\text{.}\) Untuk \(n=8\text{,}\) fungsi merupakan metrik. Dalam kasus ini, \(B(1,r)=\{1\}\) untuk \(0<r\leq2\text{,}\) \(B(1,r)=\{1,3\}\) untuk \(2<r\leq4\text{,}\) dan \(B(1,r)=X\) untuk \(r>4\text{.}\)
