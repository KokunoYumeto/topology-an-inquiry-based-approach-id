Solusi F.25.1.

Definisikan \(s:\R\to\R\) dengan \(s(x)=1\) untuk \(x\geq0\) dan \(s(x)=-1\) untuk \(x<0\text{.}\) Fungsi ini tidak kontinu di \(0\text{:}\) tetapkan \(\epsilon_0=1\text{;}\) untuk setiap \(\delta>0\text{,}\) titik \(x=-\delta/2\) memenuhi \(|x|<\delta\text{,}\) tetapi \(|s(x)-s(0)|=|-1-1|=2\geq\epsilon_0\text{.}\)
Ambil \(f=g=s\text{.}\) Kedua faktor tidak kontinu di \(0\text{,}\) sedangkan untuk setiap \(x\text{,}\) \((fg)(x)=s(x)^2=1\text{.}\) Hasil kali tersebut adalah fungsi konstan, sehingga kontinu. Jadi pernyataannya salah.
