Langkah 1. Jika \(x\in\overline{A}\text{,}\) maka \(B(x,\varepsilon)\cap A\neq\varnothing\) untuk setiap \(\varepsilon>0\text{.}\)
Langkah 2. Jika infimum himpunan jarak adalah nol tetapi tidak ada jarak yang lebih kecil daripada suatu \(\varepsilon>0\text{,}\) maka \(\varepsilon\) akan menjadi batas bawah positif.
