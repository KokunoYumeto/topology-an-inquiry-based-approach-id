Bola-bolanya adalah \(\{a\}\) untuk \(0\lt\delta\leq1\text{;}\) \(\{a,e\}\) untuk \(1\lt\delta\leq3\text{;}\) \(\{a,e,b\}\) untuk \(3\lt\delta\leq6\text{;}\) \(\{a,e,b,d\}\) untuk \(6\lt\delta\leq8\text{;}\) dan \(\{a,e,b,d,c\}\) untuk \(\delta\gt8\text{.}\)
