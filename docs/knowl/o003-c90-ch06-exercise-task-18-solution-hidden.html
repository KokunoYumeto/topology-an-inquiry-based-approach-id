Karena \(0\) rasional, \(g(0)=0\text{.}\) Ambil \(\epsilon\gt0\) dan pilih \(\delta=\epsilon\text{.}\) Jika \(|x|\lt\delta\text{,}\) maka untuk \(x\) irasional berlaku \(|g(x)-g(0)|=0\text{,}\) sedangkan untuk \(x\) rasional berlaku \(|g(x)-g(0)|=|x|\lt\delta=\epsilon\text{.}\) Jadi \(g\) kontinu di \(0\text{.}\)
Sekarang tetapkan \(a\neq0\) dan ambil \(\epsilon=|a|/2\gt0\text{.}\) Jika \(a\) rasional, maka \(g(a)=a\text{.}\) Untuk setiap \(\delta\gt0\text{,}\) pilih titik irasional \(x\) dengan \(|x-a|\lt\delta\text{.}\) Karena \(g(x)=0\text{,}\) diperoleh \(|g(x)-g(a)|=|a|\geq\epsilon\text{.}\)
Jika \(a\) irasional, maka \(g(a)=0\text{.}\) Untuk radius \(\delta\gt0\text{,}\) kerapatan bilangan rasional memungkinkan kita memilih \(x\in\Q\) dengan \(|x-a|\lt\min\{\delta,|a|/2\}\text{.}\) Pertidaksamaan segitiga terbalik memberi \(|x|\gt|a|-|x-a|\gt|a|/2=\epsilon\text{.}\) Jadi \(|g(x)-g(a)|=|x|\gt\epsilon\text{.}\) Dalam kedua kasus, negasi kekontinuan terpenuhi di \(a\text{.}\) Dengan demikian hanya \(0\) merupakan titik kekontinuan \(g\text{.}\)
