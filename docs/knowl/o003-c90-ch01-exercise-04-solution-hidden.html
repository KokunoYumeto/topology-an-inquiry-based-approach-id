Untuk hukum pertama, \(x\in(\bigcup A_\alpha)^c\) jika dan hanya jika tidak ada \(\alpha\) dengan \(x\in A_\alpha\text{;}\) ini jika dan hanya jika untuk setiap \(\alpha\text{,}\) \(x\in A_\alpha^c\text{;}\) dan ini jika dan hanya jika \(x\in\bigcap A_\alpha^c\text{.}\) Untuk hukum kedua, \(x\notin\bigcap A_\alpha\) jika dan hanya jika ada \(\alpha\) dengan \(x\notin A_\alpha\text{;}\) ini jika dan hanya jika \(x\in\bigcup A_\alpha^c\text{.}\) Dengan konvensi gabungan kosong \(\emptyset\) dan irisan kosong \(U\text{,}\) bukti juga mencakup \(I=\emptyset\text{.}\)
