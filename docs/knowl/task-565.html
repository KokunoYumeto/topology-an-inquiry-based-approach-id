Butir 12.5.a.

Misalkan \(X=\{a,b,c,d,e,f\}\) dan \(\tau= \{\emptyset, \{a\}, \{c,d\},\{a,c,d\}, \{b,c,d,e,f\}, X \}\text{.}\)
(i)
Apakah himpunan
\begin{equation*} \mathcal{B} = \{\{a\},\{a,c,d\} \} \end{equation*}
merupakan basis untuk \(\tau\text{?}\) Jika bukan, tambahkan sesedikit mungkin himpunan ke \(\mathcal{B}\) agar menjadi basis untuk topologi ini.
(ii)
Apakah himpunan
\begin{equation*} \mathcal{B} = \{\{a\},\{c,d\},\{b,c,d,e,f\} \} \end{equation*}
merupakan basis untuk \(\tau\text{?}\) Jika bukan, tambahkan sesedikit mungkin himpunan ke \(\mathcal{B}\) agar menjadi basis untuk topologi ini.
