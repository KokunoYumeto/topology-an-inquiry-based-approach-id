Butir 9.b.ii.
Andaikan \(m^2 \gt 2\text{.}\) Tunjukkan bahwa terdapat bilangan bulat positif \(n\) sedemikian sehingga
\begin{equation*} \left(m-\frac{1}{n}\right)^2~\gt~2\text{.} \end{equation*}
Jelaskan mengapa hal ini juga tidak mungkin terjadi.
