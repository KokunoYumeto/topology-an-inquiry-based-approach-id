Karena \(A\) tak kosong, ada \(a_0\in A\text{.}\) Maka bilangan real \(d(x,a_0)\) merupakan anggota \(D=\{d(x,a)\mid a\in A\}\text{,}\) sehingga \(D\neq\varnothing\text{.}\) Untuk setiap \(a\in A\text{,}\) aksioma tak-negatif metrik memberi \(d(x,a)\geq0\text{.}\) Jadi \(0\) adalah batas bawah \(D\text{.}\)
